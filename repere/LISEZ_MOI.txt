REPÈRE — Votre recherche immobilière, sans Excel
Version 1.0.0

DÉMARRAGE WINDOWS

1. Installez et ouvrez Docker Desktop avec les conteneurs Linux.
2. Arrêtez l'ancien serveur d'import Excel : il utilisait aussi le port 8765.
3. Extrayez tout le dossier repere de l'archive dans un dossier permanent.
4. Double-cliquez sur DEMARRER.bat. Le premier lancement télécharge les images
   et les dépendances ; laissez la fenêtre ouverte pendant la préparation.
5. Copiez le code affiché dans la fenêtre puis connectez-vous sur :
   http://127.0.0.1:8765

AJOUTER UNE ANNONCE DEPUIS CHROME OU EDGE

1. Ouvrez chrome://extensions ou edge://extensions et activez le Mode développeur.
2. Cliquez sur Charger l'extension non empaquetée ; sélectionnez le dossier
   extension de CE paquet Repère.
3. Dans l'extension, enregistrez le même code de connexion que dans l'application.
4. Ouvrez une annonce, cliquez sur Lire l'annonce ouverte, puis sur
   Vérifier les champs localement et Ajouter à Repère.
5. Vérifiez la fiche dans Repère. Gemini est facultatif : aucun abonnement ni
   aucune clé API n'est nécessaire pour les extractions locales.

Renseignez ensuite Mon budget, sélectionnez vos annonces dans Comparer, puis
utilisez Simuler : apport vers mensualité ou mensualité cible vers apport.

ARRETER.bat arrête les services et conserve vos données.
Paramètres > Télécharger une sauvegarde conserve aussi vos captures et scénarios.

Le guide détaillé est README.md. Les adaptations HTML sont expliquées dans
docs/PARSEURS.md. Les tests et limites vérifiés figurent dans docs/VALIDATION.md.

L'application a été testée dans Chromium avec une base SQLite temporaire.
Le démarrage Docker/PostgreSQL et les scripts Windows restent à valider
sur votre ordinateur : ce contexte ne disposait pas d'un moteur Docker.
