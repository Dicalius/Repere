REPÈRE — Votre recherche immobilière, sans Excel
Version 1.4.0

DÉMARRER

1. Installez et ouvrez Docker Desktop avec les conteneurs Linux.
2. Récupérez le dossier depuis GitHub (git clone https://github.com/Dicalius/Repere.git).
3. Dans ce dossier, la première fois : docker compose up -d --build
4. Le code de connexion s'affiche une fois dans les journaux du conteneur app
   (Docker Desktop > repere-app-1 > Logs). Ouvrez http://127.0.0.1:8765 et collez-le.
   Pour le retrouver : docker compose exec app repere token

Aucun script ni fichier .env n'est nécessaire (.env reste facultatif, voir .env.example).

METTRE À JOUR

Redémarrez le conteneur app (Docker Desktop, ou docker compose restart app). Au démarrage,
il télécharge la dernière version validée par les tests sur GitHub (branche « valide »),
installe les nouvelles dépendances si besoin, puis se lance. La base n'est pas touchée.
Si l'extension a changé : chrome://extensions > Recharger.

AJOUTER UNE ANNONCE DEPUIS CHROME OU EDGE

1. Ouvrez chrome://extensions ou edge://extensions et activez le Mode développeur.
2. Cliquez sur Charger l'extension non empaquetée ; sélectionnez le dossier extension.
3. Dans l'extension, enregistrez le même code de connexion que dans l'application.
4. Ouvrez une annonce, cliquez sur Lire l'annonce ouverte, puis sur Ajouter à Repère.
5. Vérifiez la fiche dans Repère. Gemini est facultatif.

Arrêter : docker compose stop (les données sont conservées).
Paramètres > Télécharger une sauvegarde conserve aussi vos captures et scénarios.
Le guide détaillé est README.md.
